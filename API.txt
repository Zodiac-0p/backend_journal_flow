BASE URL
http://127.0.0.1:8000/api/accounts/


====================================================
PUBLIC APIS (No Authentication Required)
====================================================

1. Check Email
POST http://127.0.0.1:8000/api/accounts/check-email/

Request Body:
{
  "email": "author@example.com"
}


2. Register New User
POST http://127.0.0.1:8000/api/accounts/register/

Request Body:
{
  "email": "author@example.com",
  "username": "author1",
  "full_name": "Author One",
  "password": "StrongPass123",
  "phone": "9876543210",
  "affiliation": "ABC University",
  "expertise": "Artificial Intelligence",
  "want_to_be_reviewer": true
}


3. Login
POST http://127.0.0.1:8000/api/accounts/login/

Request Body:
{
  "email": "author@example.com",
  "password": "StrongPass123"
}


4. Refresh Access Token
POST http://127.0.0.1:8000/api/accounts/token/refresh/

Request Body:
{
  "refresh": "your_refresh_token"
}



====================================================
AUTHENTICATED APIS
(Add Header: Authorization: Bearer <access_token>)

====================================================
EDITORIAL MANAGER / SUPER ADMIN APIS
(Add Header: Authorization: Bearer <access_token>)
====================================================

9. Promote User to Reviewer
POST http://127.0.0.1:8000/api/accounts/users/{user_id}/make-reviewer/

Example:
POST http://127.0.0.1:8000/api/accounts/users/5/make-reviewer/


10. Create Role Choice
POST http://127.0.0.1:8000/api/accounts/role-choices/

Request Body:
{
  "name": "Software Developer"
}


11. Update Role Choice
PUT http://127.0.0.1:8000/api/accounts/role-choices/{id}/

Request Body:
{
  "name": "Senior Software Developer"
}


12. Delete Role Choice
DELETE http://127.0.0.1:8000/api/accounts/role-choices/{id}/


13. Create Discipline

Request Body:

}


14. Update Discipline

Request Body:
{
  "name": "Advanced Computer Science"
}


15. Delete Discipline
DELETE http://127.0.0.1:8000/api/accounts/disciplines/{id}/
